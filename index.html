Self-Organizing Maps (SOM)

Descubre cómo una red neuronal aprende a organizar datos similares en un mapa bidimensional sin necesidad de recibir categorías previamente.

Explorar funcionamiento ↓
01 / ARQUITECTURA

¿Cómo está construido un SOM?

Un mapa autoorganizado recibe datos de entrada y los compara con una cuadrícula de neuronas. Cada neurona tiene un vector de pesos que se modifica durante el aprendizaje.

01

Datos de entrada

Son los datos que queremos organizar. Cada ejemplo se representa mediante un vector de características.

02

Capa de neuronas

Cada neurona posee un vector de pesos. Estos pesos se comparan con los datos de entrada para encontrar la neurona más parecida.

W
W representa los pesos de una neurona.

03

Mapa bidimensional

Las neuronas se distribuyen en una cuadrícula. Las neuronas cercanas mantienen una relación de vecindad.

Cada celda representa una neurona.
Conexiones entre neuronas: representan la relación de vecindad entre ellas. Cuando una neurona aprende, sus neuronas cercanas también ajustan sus pesos.
02 / PROCESO

¿Cómo aprende el SOM?

El algoritmo sigue una serie de pasos que se repiten durante el entrenamiento. Selecciona cada etapa para conocer qué ocurre.

PASO 1 DE 6

Inicialización de la red

Se crea una cuadrícula de neuronas. Cada una recibe un vector de pesos inicial, normalmente asignado aleatoriamente.

IDEA MATEMÁTICA wᵢ = [w₁, w₂, ..., wₙ] Cada neurona comienza con un conjunto de pesos.

¿QUÉ ESTÁ OCURRIENDO?

El mapa está listo para aprender

Avanza una iteración para observar cómo se selecciona una neurona y se actualizan sus pesos.

REGLA DE APRENDIZAJE
wᵢ(t+1) = wᵢ(t) + α(t) · hᵢ(t) · [x − wᵢ(t)]

α representa la tasa de aprendizaje y h representa la influencia de la vecindad.

04 / RESULTADO

¿Qué sucede después del entrenamiento?

Después de repetir el proceso, las neuronas adaptan sus pesos a la distribución de los datos. De esta manera, el mapa representa las similitudes entre los ejemplos.

ANTES

Mapa inicial

Las neuronas tienen pesos iniciales que todavía no representan la distribución de los datos.

→
DESPUÉS

Mapa organizado

Las neuronas se adaptan y las regiones cercanas representan patrones de datos similares.

Idea principal: el SOM utiliza aprendizaje no supervisado. No necesita conocer previamente las categorías de los datos, sino que aprende a organizarlos según sus características y similitudes.
